# What the shared packages already do

Generated by `devkit-shared list`; do not edit by hand. Before writing anything a site might share, look here: if a package exports it, import it. `npx devkit-shared` fails a repository that copies one of these, misses a family feature, or pins an old release.

## Family features

| Feature | Needed by | Provided by |
| --- | --- | --- |
| robots | site, static | Prelum ./robots robotsDocument (/robots.txt) |
| aiTxt | site, static | Prelum ./robots aiTxt or aiTxtResponse (/ai.txt) |
| tdm | site, static | Prelum ./robots TDM_RESERVATION_HEADERS |
| sitemap | site, static | Prelum ./sitemap sitemapDocument (/sitemap.xml) |
| llms | site, static | Prelum ./llms llmsDocument (/llms.txt) |
| head | site, static | Prelum ./head headTags (canonical, Open Graph, Twitter) |
| schema | site, static | Prelum ./schema (JSON-LD) |
| indexnow | site, static | Prelum ./indexnow submitIndexNow (site-api indexNowHook on a Carrel site; prelum-indexnow after a static deploy) |
| securityTxt | site, static | site-runtime ./security-txt (/.well-known/security.txt) |
| headers | site, static, private, worker | site-runtime ./headers buildSecurityHeaders (or a ./sites entry given to ./static-site staticSite) |
| csp | site, static, private | site-runtime ./csp buildContentSecurityPolicy (or a ./sites entry given to ./static-site staticSite) |
| cspReport | site, static, private | site-runtime ./csp-report receiveCspReport (./static-site staticSite receives them for a static site) |
| health | site, private | site-runtime ./health healthResponse (/health) |
| capsomer | site, static, private | Capsomer's capsomer/base.css (tokens, element styles, the site layer), then its components |
| a11y (a warning) | site, static, private | capsomer/testing expectNoAxeViolations (or @axe-core) in a browser test |
| noindex (a warning) | site, static | a robots noindex meta or X-Robots-Tag: noindex on each admin, login, signin or console route |
| feedLink (a warning) | site, static | `<link rel="alternate" type="application/rss+xml">` (or atom, or feed+json) in the head |
| backup | any app with a D1 database | d1-dump runCheckedBackup and backupHealth |
| assetCache | any React Router app (/assets/*, and /islands/* with devkit ./islands) | public/_headers: Cache-Control: public, max-age=31536000, immutable |
